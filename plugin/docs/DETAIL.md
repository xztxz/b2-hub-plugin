# B2 中枢（DSH 宿主）

把 DSH 接到本地 **B2 Markdown 库**上：笔记与任务只有一份文件真相源，工具和侧栏面板都读写它。

这是「B2 笔记/任务中枢」的第一个宿主。设计见仓库根 `DESIGN.md`，行为契约见 `HOST-CONTRACT.md`。

## 工具

**读**

- `b2_status`：库是否可用、笔记数、未完成任务数。
- `b2_list_notes`：列笔记元信息，可按类型或关键词过滤。
- `b2_read_note`：读笔记的 frontmatter、正文和内容 hash。
- `b2_list_tasks`：列 checkbox 任务，按截止日排序，可按项目/收件箱和 `@姓名` 过滤。

**写**（都带 `expect` hash，冲突时最后写入赢并提示）

- `b2_create_note`：新建笔记，同名不覆盖。
- `b2_write_note`：写已存在的笔记。
- `b2_toggle_task`：勾选 / 取消一行任务。
- `b2_set_due`：设置或清除截止日。
- `b2_assign`：增删 `@姓名` 指派。一个任务可以有多名负责人：`name` 给一个，`names` 一次给多个；只动点名的那几个人，其余负责人不受影响。
- `b2_overview`：重新生成 `90-Overview.md`。

**收拾与维护**

- `b2_capture`：随手记一句话进收件箱（或指定项目），文字里的 `📅2026-11-20`、`@姓名` 会被识别；已知人员会升级成 `@[[姓名]]` 双链。
- `b2_move_task`：把一行任务整行搬到另一篇笔记（收件箱 ↔ 项目），日期、指派、勾选状态原样保留。
- `b2_set_status`：改项目状态（`active` / `paused` / `blocked` / `done`），只对 `type: project` 生效。
- `b2_person_history`：某个人的进行中 / 已完成任务历史，每条标注所属项目。
- `b2_init_library`：初始化库（建目录与 `90-Overview.md`；仅新库放 1 个示例项目 + 1 个示例人员）。只在用户明确要建库时调用。

## 一条硬约定

**面板上的任何操作都会立刻写进对应笔记。** 改截止日、换项目、加负责人、勾完成，在 Obsidian 里打开同一篇笔记就能看到同一份改动；关掉 DSH 也不会丢。反过来，你在 Obsidian 里改的内容，面板刷新后同样会看到。

这条约定意味着：不存在"只在面板里生效"的状态，也没有需要导出才能拿到的东西。

## 侧栏面板

一个面板、三个视角，顶部切换：

- **待办**：**只显示还没归到项目的任务**（收件箱里的那些），与负责人无关——分给谁都不会让它离开这一页，只有把归属改成某个项目才会。分成「逾期 / 本周 / 未排期」三组，行内右侧的归属下拉就是"归到哪个项目"。
- **项目**：看板视图——每个项目一列，列头是项目名与未完成/逾期数，列里是它的任务。列放不下时**自动换行到下一排**，不会横向挤出一条滚动条。右上角「＋ 新建项目」可以直接建（会在 `10-Projects/<名字>/<名字>.md` 生成笔记）。
- **排序**：顶部三个胶囊「紧急度 / 任务量 / 创建时间」对**任务与项目、人员同时生效**——任务按截止日、工时、所在笔记的创建日排；项目按逾期与最早截止、未完成数、创建日排；人员按逾期、任务量、创建日排。默认按紧急度，切换结果会记住，下次打开仍是这个模式。
- **任务行**：标题独占一行，日期、负责人、归属笔记都放在第二行，窄列里也不会把标题挤成省略号。**负责人点开是一排可勾选的人名芯片**，勾几个就是几个人共同负责（行上显示「张三 +1」，鼠标悬停可看全名单）。
- **自适应**：项目页右上角有「自适应：开/关」开关，旁白会显示当前列宽。开启时同时看**窗口宽度**和**项目数量**——项目少就把列铺宽（单项目最多 720px），项目多就收窄到可读宽度并换行排布；窗口窄于 720px 时改成单列纵向堆叠。关闭时固定 320px 列宽。换电脑或换宿主时先试这个开关。

## 设置：换电脑后的第一步

面板页头右侧有 **⚙ 设置** 按钮，点开从右侧滑入设置页：

- 显示当前库根路径与它是否可用（三态：不存在 / 存在但读不到 / 可用，并显示笔记数）
- 「选择文件夹…」直接调宿主的目录选择器，选完先**探查**这个目录（不保存、不写入）：已有库会显示笔记数并提示「点保存路径生效」，空文件夹会提示去初始化
- 可以改路径并「保存路径」（写入插件配置，插件会重启生效）
- 路径写法随便挑：`C:\Users\你\Documents\B2`、`~/vault/B2`、`%USERPROFILE%\vault\B2` 都行——插件会展开 `~` 与环境变量，保存后把展开的绝对路径显示回来
- 「初始化此库」作用在**输入框里的那个路径**上（哪怕还没保存）：补全 `00-Inbox / 10-Projects / 20-People / 90-Overview.md`；**只在新库时**额外放 1 个示例项目 + 1 个示例人员（各一个，不铺满）。目录已存在时会先确认一次
- 库不存在时，主面板的错误页直接给「打开设置」入口——首装不需要先去猜侧栏哪里点

> **库不绑定 Obsidian。** 插件只认文件夹：把库放在任意位置，Obsidian 里「打开文件夹作为库」就能看到同一批笔记；反过来在 Obsidian 里写的任务行，面板刷新后一样认。库目录里没有任何私有数据库或索引文件，只有 `.md`（`.obsidian/` 永不被扫描）。

> 为什么不在 DSH 设置里：侧栏那一行是宿主自己画的（图钉也是），插件没有可插入按钮的槽位；设置放在 B2 自己的页头，离使用场景更近。

初始化不覆盖任何已有文件；已存在的库重复点只会补缺失项，不会再加示例。

新电脑上的顺序：装插件 → 面板里 ⚙ 设置连到已有库（或初始化新库）→ 回面板。注意 Obsidian 本身不是必需的，插件只认文件夹。
- **人员**：和项目页一样的竖列看板——每人一列，列头是姓名与「角色 · N 个任务 · 逾期 M」，列里是他名下的任务；人数多时同样按宽度换行。**点击姓名从右侧滑出该人员的任务历史**：可用「全部 / 进行中 / 已完成」筛选，每条标注所属项目，并可用「紧急度 / 任务量 / 创建时间」排序；滑入页宽度随窗口自适应（窄屏铺满、宽屏约占 42%），点左侧遮罩或按 **Esc** 收回。

每一行都能勾完成、改截止日、改负责人、搬移笔记（负责人点开是一排人名芯片，勾几个人就是几个人共同负责；「清除」取消全部负责人）。

顶部有一个**随手记**输入框：打一句话回车，就以任务行写进收件箱（收件箱笔记不存在时自动创建），随后出现在**待办**页等你归项目。旁边可以选截止日期与负责人（要多人就再选一次，会往文字里追加第二个 `@[[姓名]]`），也可以直接在文字里写 `@姓名`、`📅2026-11-20`。

每行任务右侧还有一个日期框和一个目标下拉：日期框直接改截止日（清空即清除），目标下拉选中另一个笔记就把该行整行移过去（截止日、指派原样保留），用来把收件箱里的东西归到项目里。

底部有**按人**清单：每个人的名字、角色、在手任务数与逾期数。

## 人员

`20-People/` 下每篇 `type: person` 的笔记就是一个人，标题即姓名，可选 `role` 字段写角色。

- 新增人员：`b2_create_person`，或在 Obsidian 里自己写一篇。
- **指派校验**：`b2_assign` 加 `@姓名` 时，这个人必须已经存在，否则会被拒绝——这样 `@` 不会变成没人认领的装饰。一次加多人时，缺的人会一起报出来。
- **双向链接**：指派写成 `@[[张三]]`（多人就是 `@[[张三]] @[[李四]]`），任务所在笔记会自动出现在每个人笔记的「反向链接」里；每人的笔记里还会生成一段 `## 任务`，分「进行中 / 已完成」两小节，用 `[[笔记名]]` 链回任务所在笔记——已完成的记录也会一直保留在这里。指派、随手记、勾选、改期、搬移后会自动同步相关的人，`b2_sync_people` 可以全量刷新。

面板通过同源端点 `/b2-hub/api` 取数——客户端不直接碰文件系统。没有 web 服务时面板不出现，工具照常工作。

## 库的约定

```
B2/
  00-Inbox/
  10-Projects/<项目名>/<项目名>.md
  20-People/
  90-Overview.md
```

- 笔记：Markdown + YAML frontmatter（`type`、`status`、`priority`、`created`、`due`）。
- 任务：`- [ ] 标题 📅YYYY-MM-DD @姓名`，一行可多人。
- 编码 UTF-8 无 BOM、换行 LF；同步交给外部工具，插件不实现同步。

## 限制

- **不自动建库**：库根不存在时直接报错，不会悄悄替你创建目录；要建库就点设置页的「初始化此库」（或 `b2_init_library`）。
- **不做同步与冲突合并**：同一任务在多端同改时，以文件最后写入为准，冲突会在结果里标出。
- **改代码后要重启 DSH**：Node 会缓存已加载的模块，刷新页面不会重载插件代码。
- 库根由插件配置的 `root` 指定，默认 `~/vault/B2`（展开成当前用户家目录），不写死任何盘符。
